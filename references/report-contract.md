# 输出契约

## 群聊摘要

```markdown
## 高热内容追踪｜<专项/方向>

结论：<一句话说明最值得做什么，或暂不建议追>
抓取时间：<YYYY-MM-DD HH:mm Asia/Shanghai>
范围：<平台 + 时间窗口 + 样本数>

### 立即测试
1. <选题方向>
   - 适合：<平台 / 达人类型 / 专项能力>
   - 依据：<2–3 条可点击样本标题>
   - 可复用机制：<1–2 个>
   - 怎么拍：<短执行骨架>
   - 风险：<最大风险和失效窗口>

### 本周储备/继续观察
- <方向 + 原因>

### 不建议追
- <热点 + 原因>
```

摘要以结论和链接为主，不展示复杂评分表、不堆满所有搜索结果。

## 交付规则

- 强推荐方向至少引用 3 条真实样本、2 个不同账号；
- 每个事实性热点结论就近附来源；
- 标题使用可读名称，URL 保持可点击；
- 公开数字必须原样标注平台和抓取时间；
- 不输出平台 token、内部 source ID、客户/供应商敏感信息；
- 用户要求“详细报告”时优先完整结构；只问“最近有什么可做”时先给摘要，允许再展开；
- 需要飞书文档时，先生成内容，再通过独立文档写入能力执行；本 Skill 不隐式写文档。
