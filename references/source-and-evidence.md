# 热点来源与证据协议

## 1. 两条证据链必须分开

### 热点证据链

证明“这个话题/格式现在受到关注”，可来自：

- 平台官方榜单、创作中心、站内趋势页；
- 站内搜索结果、话题页、搜索联想；
- 搜索趋势与公开聚合榜单；
- 新闻、行业媒体、社群讨论。

### 爆款内容证据链

证明“这条作品在平台上表现强”，优先来自：

- 原作品页；
- 创作者主页；
- 平台公开作品数据；
- 用户提供且可核验的截图/平台后台数据。

媒体文章、排行榜摘要或搜索片段可以发现线索，但不能代替原作品证据。

## 2. 来源等级

| 等级 | 含义 | 可支持的结论 |
|---|---|---|
| A | 平台原页、官方榜单、官方创作中心、用户授权后台 | 作品存在、公开数据、榜单位置、发布时间 |
| B | 可复核的搜索页、话题页、公开聚合榜、权威行业资料 | 讨论存在、关键词趋势、热点线索 |
| C | 媒体报道、二次转载、营销文章、搜索摘要 | 仅作发现线索，需回原页复核 |

任何来源都要记录 `captured_at`。平台原页失效、登录阻断或数据不可见时，写明失败，不拿摘要补齐数据。

## 3. 平台优先级

### 抖音

1. 抖音原作品/作者主页；
2. 抖音热点、巨量算数等公开官方页面；
3. 搜索结果与可信报道作线索。

### 小红书

1. 小红书原笔记/作者主页；
2. 小红书站内搜索、话题、创作服务公开信息；
3. 搜索结果与可信报道作线索。

### 补充平台

B站、微博、百度、知乎、微信指数、节日节点和行业站点可用于发现用户情绪、表达格式和跨平台信号，但最终是否适合抖音/小红书仍需目标平台样本验证。

## 4. 样本标准化字段

每条样本至少保留：

```text
platform
creator_name
creator_homepage_url（如可得）
content_title_or_hook
content_url
published_at
captured_at
public_metrics（只记录实际可见字段）
follower_count（如可见）
source_level
verification_status
observable_material（正文/字幕/关键帧/评论/数据）
limitations
```

`public_metrics` 不做跨平台统一总分。抖音、小红书各自在相同指标口径内比较；缺字段留空，不以 0 代替。

## 5. 去重与样本质量

- 同一作品的短链、长链、分享参数合并；
- 搬运、合集和营销聚合页不算独立样本；
- 同一账号同一内容的多平台分发只算一个内容机制样本；
- 至少两个账号，避免把单一大号风格当成平台趋势；
- 大号样本必须标注账号体量干扰；优先同时寻找中小账号的异常高表现；
- 只有单条样本时可拆解个案，但不得声称形成规律。

## 6. 生命周期判断

只有存在至少两个不同时间点，或多条带发布时间的近时样本时才判断：

- 萌芽：样本少，近期首次出现，尚未大量同质化；
- 上升：较新样本数量或公开表现随时间增强；
- 高位：大量内容正在集中出现，但仍有新增强样本；
- 饱和：同质化严重，新样本缺乏新机制；
- 衰退：最新样本和讨论明显减弱；
- 未知：数据不足。

不能用单个热榜排名推导增速，不能根据模型记忆判断“今天在热”。

## 7. 失败与降级

- 目标平台不可访问：使用公开搜索和补充平台找线索，但所有未回原页样本标“部分核验”；
- 没有实时来源：转为“常青需求/节点机会”，明确不是实时热点；
- 找不到 3 条有效样本：列入观察池，不给“立即测试”；
- 作品能打开但看不到画面/字幕：只分析标题、描述、评论与公开数据，标注无法判断剪辑和视觉；
- 排名、播放或互动无法核验：不引用该数字。
